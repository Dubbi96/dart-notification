## 1. 서비스 개요

| 항목 | 내용 |
|------|------|
| **서비스명** | 공시온 |
| **한 줄 소개** | 관심 기업의 DART 공시를 실시간으로 알려주는 모바일 알림 서비스 |
| **플랫폼** | Android (iOS 추후 확장) |

### 서비스 비전

> 개인 투자자가 공시 정보를 **놓치지 않고**, **빠르게**, **원하는 것만** 받아볼 수 있는 환경을 만든다.

---

## 2. 배경 및 문제 정의

### 현황

DART(전자공시시스템)는 상장기업의 공시 정보를 공개하는 금융감독원 운영 시스템으로, 하루 평균 수백 건의 공시가 올라온다. 공시에는 기업의 실적, 합병, 증자, 임원 변동 등 **투자 판단에 직접적인 영향을 주는 정보**가 포함되어 있다.

### 문제

| 문제 | 설명 |
|------|------|
| **접근성 부족** | DART 웹사이트는 모바일 환경에 최적화되어 있지 않아, 이동 중 확인이 어렵다 |
| **정보 과부하** | 하루 수백 건의 공시 중 내가 관심 있는 기업의 공시를 직접 찾아야 한다 |
| **시의성 문제** | 공시 확인이 늦어지면 이미 주가에 반영된 후일 수 있다 |
| **필터링 부재** | 관심 없는 공시 유형(예: 정기 보고서)까지 모두 확인해야 한다 |

### 기존 솔루션의 한계

- **증권사 앱**: 일부 공시 알림을 제공하나, 유형별·키워드별 세밀한 필터링 불가
- **DART 웹사이트**: 알림 기능 없음, 수동 검색 필요
- **뉴스 알림**: 공시 원문이 아닌 기사 기반으로 시차 발생, 일부 공시 누락
- **텔레그램 공시 알림방**: 전체 공시를 무차별적으로 수신해야 하므로, 관심 기업·유형만 선별 불가

## 3. 솔루션

### 핵심 가치 제안 (Value Proposition)

**"내 관심 기업의 공시를, 원하는 조건으로, 실시간 푸시 알림으로 받는다."**

### 주요 기능

| 기능 | 설명 |
|------|------|
| **관심 기업 관리** | 최대 30개 기업을 등록하고, 자동완성 검색으로 빠르게 추가 |
| **맞춤 알림 설정** | 7개 공시 유형(정기·주요사항·발행·지분·감사·거래소·기타) 중 원하는 것만 선택 |
| **키워드 필터** | 특정 키워드가 포함된 공시만 알림 수신 |
| **실시간 푸시 알림** | 조건에 맞는 공시 등록 시 즉시 모바일 푸시 발송 |
| **공시 원문 열람** | 앱 내에서 공시 원문(DART)을 바로 확인 |
| **알림 히스토리** | 받은 알림 목록 확인 및 읽음/미읽음 관리 |
| **기업 정보 조회** | 관심 기업의 기본 정보(대표자, 업종, 주소 등)를 앱에서 확인 |
| **공시 저장** | 중요한 공시를 북마크하여 나중에 다시 확인 |

> 각 기능의 상세 정의는 **기능정의서** 참조

## 4. 타겟 유저

### 주요 사용자층

**국내 주식 개인 투자자** — 특히 특정 기업의 공시를 꾸준히 추적해야 하는 투자자

### 페르소나

#### 페르소나 A: 직장인 투자자 (30대)

| 항목 | 내용 |
|------|------|
| **상황** | 근무 중 DART를 수시로 확인할 수 없음 |
| **니즈** | 보유 종목의 주요 공시(합병, 증자, 실적)만 실시간으로 알고 싶음 |
| **기대** | 퇴근 후가 아닌, 공시 발생 즉시 확인하여 빠른 투자 판단 |

#### 페르소나 B: 적극적 개인 투자자 (40대)

| 항목 | 내용 |
|------|------|
| **상황** | 10개 이상 관심 종목을 모니터링 중 |
| **니즈** | 종목별로 다른 유형의 공시를 선별적으로 추적하고 싶음 |
| **기대** | 정보 과부하 없이 필요한 공시만 정리되어 전달됨 |

#### 페르소나 C: 텔레그램 공시방 이용자 (20~30대)

| 항목 | 내용 |
|------|------|
| **상황** | 텔레그램 공시 알림방으로 공시를 받고 있으나, 모든 공시가 무차별 전송됨 |
| **니즈** | 관심 기업의 공시만 선별해서 받고 싶음 |
| **기대** | 불필요한 알림 없이, 내가 설정한 조건의 공시만 깔끔하게 수신 |

## 5. 기술 개요

### 기술 스택

| 영역 | 기술 |
|------|------|
| **모바일 앱** | React Native (Expo), TypeScript |
| **백엔드 서버** | NestJS, TypeScript |
| **데이터베이스** | PostgreSQL |
| **인증** | 카카오 OAuth 2.0 (JWT) |
| **푸시 알림** | Expo Push Notification Service |
| **외부 API** | DART Open API (금융감독원) |
| **인프라** | GCP (추후 AWS 이관 예정) |
| **배포** | GitHub Actions (서버), EAS (모바일) |

### 시스템 구조

```
┌─────────────┐     ┌──────────────────┐     ┌───────────────┐
│  모바일 앱   │────▶│   백엔드 서버     │────▶│  PostgreSQL   │
│  (Expo)     │◀────│   (NestJS)       │◀────│  (GCP)        │
└─────────────┘     └──────────────────┘     └───────────────┘
       ▲                    │      ▲
       │                    │      │
       │              ┌─────▼──┐   │
       │              │ DART   │   │
  푸시 알림           │ Open   │   │
       │              │ API    │   │
       │              └────────┘   │
┌──────┴────────┐          10분마다 수집
│  Expo Push    │
│  Service      │
└───────────────┘
```

### 공시 수집 → 알림 발송 파이프라인

```
[10분 주기 스케줄러]
        │
        ▼
  DART API에서 최신 공시 수집
        │
        ▼
  중복 확인 (rcpNo 기준)
        │
        ▼
  공시 유형 자동 분류 (7개 카테고리)
        │
        ▼
  사용자 매칭 (관심기업 + 유형 + 키워드)
        │
        ▼
  조건 일치 사용자에게 푸시 알림 발송
        │
        ▼
  알림 히스토리 기록
```
