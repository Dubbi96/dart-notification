## 항목별 상세 설명

### 1. 고객 세그먼트 (Customer Segments)

국내 주식에 투자하는 **개인 투자자** 중, 특정 기업의 공시를 지속적으로 추적할 필요가 있는 사용자를 대상으로 한다.

- 보유 종목의 공시를 실시간으로 확인하고 싶은 직장인 투자자
- 다수 종목을 모니터링하며 정보 과부하를 겪는 적극적 투자자
- 텔레그램 공시방 등 기존 채널의 무차별 알림에 불편을 느끼는 투자자

### 2. 가치 제안 (Value Propositions)

- **선별적 알림**: 관심 기업 + 공시 유형 + 키워드 조합으로, 필요한 공시만 수신
- **실시간성**: 10분 주기 수집으로 공시 발생 직후 푸시 알림 전달
- **편의성**: 모바일 앱에서 알림 수신부터 원문 확인까지 한 번에 처리
- **기업 정보 제공**: 관심 기업의 기본 정보(대표자, 업종, 주소 등) 조회 가능

### 3. 채널 (Channels)

- **Google Play Store**: 주요 배포 채널 (Android)
- **투자 커뮤니티**: 네이버 카페, 주식 커뮤니티 등을 통한 자연 유입 기대

### 4. 고객 관계 (Customer Relationships)

- **맞춤 설정**: 사용자가 직접 알림 조건을 세밀하게 설정
- **푸시 알림**: 조건 매칭 시 자동 알림으로 지속적 재방문 유도
- **비로그인 둘러보기**: 가입 전 서비스 체험 가능 (진입 장벽 최소화)

### 5. 수익원 (Revenue Streams)

프리미엄(Freemium) 모델을 채택하여, 기본 기능은 무료로 제공하되 사용량과 부가 기능에 제한을 둔다.

### 6. 핵심 자원 (Key Resources)

- **DART Open API**: 금융감독원이 제공하는 공시 데이터 원천
- **기업 마스터 데이터**: 11만+ 기업의 고유번호, 종목코드, 시장 구분 등
- **서버 인프라**: GCP 기반 백엔드 서버 및 데이터베이스
- **Expo Push Service**: 모바일 푸시 알림 발송 인프라

### 7. 핵심 활동 (Key Activities)

- **공시 수집/분류**: DART API에서 10분 주기로 신규 공시를 수집하고 7개 유형으로 자동 분류
- **사용자 매칭 및 알림 발송**: 관심기업 + 유형 + 키워드 조건에 맞는 사용자에게 푸시 전송
- **앱 유지보수**: 안정적 서비스 운영, 기능 개선, 사용자 피드백 반영

### 8. 핵심 파트너 (Key Partnerships)

| 파트너 | 역할 |
|--------|------|
| **금융감독원 (DART)** | 공시 데이터 제공 (Open API) |
| **카카오** | 사용자 인증 (OAuth 로그인) |
| **Google Play** | 앱 배포 플랫폼 |
| **GCP** | 서버 인프라 (추후 AWS 이관 예정) |

### 9. 비용 구조 (Cost Structure)

| 항목 | 비고 |
|------|------|
| **서버/인프라** | GCP 운영비 (추후 AWS 이관) |
| **DART API** | 무료 (일일 요청 제한 존재) |
| **Google Play** | 개발자 등록비 $25 (1회) |
| **Expo Push** | 무료 티어 (소규모 사용자 대응 가능) |
| **도메인/SSL** | 커스텀 도메인 및 인증서 비용 |
