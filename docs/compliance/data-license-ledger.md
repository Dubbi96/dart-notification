## 1. KRX 정보데이터시스템 / Data Marketplace 오픈API

### 1-1. 사용 실태 (prod)

- **엔드포인트**: `https://data-dbg.krx.co.kr/svc/apis/sto/*`, `/idx/*` (일봉·코스닥·지수·ETF·종목기본정보)
- **코드 위치**: `backend/src/engine3-quant-market/market-data/krx-api.service.ts` L73 (`KRX_BASE_URL` 기본값), L124·L157·L188-189·L248
- **인증**: `KRX_API_KEY` (AUTH_KEY 헤더) — 즉, **KRX Data Marketplace OPEN API 포털(openapi.krx.co.kr)에서 발급받는 공식 오픈API**이며, 해당 포털의 이용약관이 적용된다.
- **용도**: 전 종목 일봉·지수·ETF 수집 → DB 축적 → 앱 화면(차트·시세)에 사용자 노출 + 내부 분석(Event Study·백테스트)

### 1-2. 약관 원문 인용 (조사일 2026-07-16)

- **출처 URL**: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp (KRX Data Marketplace OPEN API 이용약관, 국문)

> **제6조 제2항** — "API 이용자는 API 서비스를 **비상업적인 목적으로만** 이용할 수 있으며, API 서비스를 이용한 결과에 대한 **대가를 제3자에게 청구해서는 아니된다**."
>
> **제6조 제3항** — "API 이용자는 API 서비스를 이용한 결과의 앞, 뒤, 중간 등에 다른 내용을 삽입하거나 왜곡할 수 없고, 타인으로 하여금 결과의 내용 및 의도 등을 오인하게 해서는 아니된다."
>
> **제11조 제2항** — "API 이용자는 한국거래소로부터 제공받은 정보를 **제3자에게 제공할 수 없다**."
>
> **제11조 제4항** — "API 이용자가 제2항을 위반하였을 경우 한국거래소는 이용승인을 철회하고 API 서비스를 중단할 수 있다."
>
> **제11조 제1항** — "한국거래소는 API 이용자가 관련 법령 또는 본 약관을 준수하지 않는 경우 API 이용자의 사용을 중지할 수 있다."

참고 — 정보데이터시스템 웹사이트(data.krx.co.kr) 자체의 홈페이지 이용약관(출처: https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd, 조사일 2026-07-16)에도 유사 제한이 존재:

> **제12조 제2항(이용자의 의무)** — "이용자는 당 사이트의 정보를 거래소의 사전 허락 없이 복사·복제·배포·전송·공중송신하여서는 아니 됩니다."
>
> **제13조(지식재산권)** — "당 사이트의 화면, 프로그램, 문서, 로고 등 모든 저작권과 지식재산권은 거래소 또는 정당한 권리자에게 귀속됩니다."

### 1-3. 판정

| 쟁점 | 판정 | 근거 |
|------|------|------|
| 내부 분석용 사용(백테스트·Event Study, 비노출) | **조건부 허용** | 제6조②의 '비상업적 목적' 내로 해석 가능. 단 유료화(Pro 구독 등) 시점부터는 서비스 전체가 상업 목적이 되어 재판정 필요 |
| 무료 앱에서 사용자에게 시세 표시(재배포) | **불명 — 서면질의 필요** | 제11조②가 '제3자 제공'을 일괄 금지. 앱 사용자에게 차트·시세로 표시하는 행위가 '제3자 제공'에 해당하는지가 핵심 쟁점. 문언상으로는 금지로 읽히나, 무료·출처표기·비상업 조건 하 허용 관행이 있는지 KRX 공식 회신으로만 종결 가능 |
| 유료화(구독 과금) 후 사용 | **금지** | 제6조② '비상업적 목적으로만' + '대가를 제3자에게 청구 금지' 명문. 유료 구독에 KRX 데이터가 포함되면 문언상 정면 위반 |

**종합: 금지/불명 — 서면질의 필요.** 질의 발송 전까지의 잠정 방침:
- 현행 무료 단계 유지(비상업 요건은 현 단계에서 충족)하되, 질의를 즉시 발송해 회신을 리스크 방어 증거로 확보한다.
- 유료화 결정은 KRX 판정 종결(허용/조건부/금지 중 하나로 문서화)을 **선행 게이트**로 한다.
- '재배포 금지' 확정 시 §4의 KIS 폴백 전환 계획을 발동한다.

## 2. KIS OpenAPI (한국투자증권)

### 2-1. 사용 실태 (prod)

- **코드 위치**: `backend/src/engine3-quant-market/market-data/kis-api.service.ts` (실시간 현재가·분봉), Engine5 모의매매의 실가 조회 경로
- **인증**: 오너 **개인 계좌 기반 개인용 API 키 1개**를 서버에 두고, 그 키로 조회한 시세를 전체 앱 사용자에게 표시 — **개인 키 단일 창구 구조**
- **용도**: 실시간 현재가(사용자 노출), 분봉 축적(내부), 모의주문 체결가 산정(내부), (M11 이후) 본인 계좌 실주문

### 2-2. 약관 원문 인용 (조사일 2026-07-16)

**(a) KIS Developers 포털 안내 — 시세정보 이용 범위** (출처 URL: https://apiportal.koreainvestment.com/about-open-api):

> "**시세정보는 계좌를 보유한 개인 고객이 자기 자산의 투자 목적에 한해 이용할 수 있으며, 제3자 제공은 불가**합니다."
>
> "**법인 고객은 API 시세정보 이용 전 코스콤 등 거래소와 별도 시세정보이용계약을 반드시 체결**해야 합니다."

**(b) 코스콤 시세정보 이용 일반 원칙** (출처 URL: https://www.koscom.co.kr/portal/main/contents.do?menuNo=200407, 자주하는 질문):

> "정보의 **최종 이용자에 의한 정보의 제3자 제공 또는 게시는 원칙적으로 금지**합니다."

**(c) 오픈 API 서비스 이용 약관(제휴 이용기관_사용자, 제정 2022.8.8 / 개정 2025.6.4)** (출처 URL: https://file.koreainvestment.com/updata/namo/09101613%EC%98%A4%ED%94%88API%EC%84%9C%EB%B9%84%EC%8A%A4%EC%9D%B4%EC%9A%A9%EC%95%BD%EA%B4%80_%EC%A0%84%EB%AC%B8.pdf — PDF 전문 4쪽 아카이브: 조사일에 취득, 원문 보관):

> **제3조(적용범위)** — "본 약관은 사용자가 회사의 오픈 API 서비스를 이용하여 처리하는 **조회(시세정보, 계좌정보, 잔고, 거래내역 등), 매매주문업무 등**에 대하여 적용된다."
>
> **제1조(목적)** — "…오픈 API 서비스를 이용함에 있어 …**본인 명의 계좌의 금융 서비스를 이용하고자 하는 개인**(이하 "사용자"라 한다)과 회사 간의 권리, 의무 및 책임사항을 명확히 규정함을 목적으로 한다."

※ 이 PDF는 상업적 이용·재배포를 직접 금지하는 조항은 담고 있지 않으나, 적용범위·목적 조항이 "본인 명의 계좌" 이용을 전제한다. 재배포 금지의 직접 근거는 (a)·(b)의 포털 안내 및 코스콤 시세분배 규정이다.

### 2-3. 판정 — ⚠ 개인용 약관의 재배포 쟁점 (필수 병행 기록)

| 쟁점 | 판정 | 근거 |
|------|------|------|
| 본인 계좌 주문·잔고 조회(M11 실주문 포함) | **허용** | 약관이 예정한 본래 용도("본인 명의 계좌의 금융 서비스"). 쟁점 없음 |
| 오너 개인 키로 조회한 시세의 자기(오너) 이용 | **허용** | "자기 자산의 투자 목적" 문언 그대로 |
| **오너 개인 키로 조회한 시세를 앱 사용자 전체에게 표시** | **금지 우려 — 서면질의 필요** | "제3자 제공은 불가" 명문. 현재 서버 단일 개인 키로 전체 사용자에게 시세를 뿌리는 구조는 **KRX와 동일한 재배포 쟁점을 그대로 안고 있다**. KRX만 고치고 KIS를 누락하면 같은 구멍이 남는다 |
| 법인 전환 후 시세 재배포 | **조건부** | 법인 고객으로서 **코스콤 등과 별도 시세정보이용계약(유료)** 체결 시 가능 — 확실한 합법 경로이나 월 비용 발생. 유료화 시점의 정식 경로 후보 |

**종합: 조건부/불명 — 서면질의 필요.** §4의 폴백 계획은 "KIS로 단일화하면 끝"이 아니라
**KIS 쪽 재배포 쟁점도 함께 종결(질의 또는 법인 시세계약)해야 성립**함을 전제로 한다.

> "**민간기업 등이 공시정보를 활용한 새로운 서비스를 개발할 수 있도록** 상장사 재무정보 및 지분현황 등 공시정보 23종을 오픈API로 제공" — "활용을 원하시는 **누구든지(개인, 기업, 기관 등)** 이용할 수 있습니다."

## 4. KIS 폴백 전환 계획 (KRX 재배포 금지 판정 시)

KRX 서면질의 회신이 "앱 재배포 금지"로 확정될 경우의 전환 시나리오. **판정 결과가 최악이어도
마이그레이션 비용이 낮음을 사전 확인하는 것이 목적**이다.

### 4-1. 원칙: 노출/내부 이원화

| 계층 | 현행 | 전환 후 |
|------|------|---------|
| **사용자 노출 시세** (앱 화면·차트·알림) | KRX 일봉·지수 + KIS 실시간 혼용 | **KIS 경로로 단일화** — engine3에 KIS 실시간이 이미 통합·검증돼 있어(현재가·분봉) 노출 계층의 소스 스위치만 필요 |
| **내부 분석용** (Event Study·백테스트·Buy Score 입력, 화면 비노출) | KRX 일봉·지수·ETF | **KRX 유지** — 제6조②의 '비상업적 목적' 내부 이용으로 한정하는 시나리오. 단, 회신이 내부 이용까지 금지로 해석되면(이례적·저확률) KIS 일봉 API로 수집 경로 자체를 교체 |

### 4-2. 전환 작업 목록 (예상 규모: 소~중)

1. **노출 표면 인벤토리**: KRX 산 데이터가 사용자에게 보이는 화면 전수 목록화(일봉 차트·지수 헤더·ETF 목록 등) — 조회 계층이므로 M10 모의운용 무오염.
2. **소스 스위치**: 노출용 일봉·지수 조회를 KIS 기간별시세 API(일/주/월봉 제공)로 교체. DB 스키마 변경 불요(동일 캔들 구조), 서비스 레이어의 provider 분기만 추가.
3. **출처 표기 갱신**: `data-sources` 법적 고지·차트 하단 주석을 "시세 출처: 한국투자증권(지연 데이터 가능)"으로 갱신.
4. **KRX 격리 가드**: KRX 산 테이블/컬럼에 "내부 분석 전용 — 사용자 노출 금지" 주석 + 노출 API에서 KRX provider 사용 시 lint/테스트로 차단.
5. **지수 공백 보완**: KIS 업종/지수 시세 API로 KOSPI·KOSDAQ 지수 노출 대체(이미 KIS에 존재). ETF는 KIS 종목시세로 동일 처리.

### 4-3. 전제 조건 (§2-3과 연동)

- 이 폴백은 **KIS 측 재배포 쟁점이 먼저 종결되어야 유효**하다. 경로는 두 가지:
  - (a) KIS/코스콤 서면질의로 "무료 앱 내 출처표기 표시 허용" 회신 확보, 또는
  - (b) 법인 전환 + 코스콤 시세정보이용계약 체결(유료 — 유료화 시점과 묶어 결정).
- 둘 다 불가 판정이면 최후 폴백은 **공공데이터포털(data.go.kr) 금융위원회 시세 API**(공공데이터법 적용, 상업 이용 허용) — 지연 데이터 한계가 있으나 무료 앱 표시용으로는 성립.

### 4-4. 트리거·시점

- **트리거**: KRX 회신 수신(예상 수 주) 또는 M10 졸업 게이트(≈2026-08-05) 중 먼저 오는 시점에 판정 종결.
- 회신 지연 시: 졸업 게이트에서는 "질의 발송 완료 + 잠정 방침(무료 유지·유료화 보류)"으로 조건부 통과 처리하고, 회신 도착 즉시 본 원장을 갱신한다.
