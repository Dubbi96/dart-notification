## 질의서 전문

---

**제목: 오픈API 제공 데이터의 모바일 앱 내 표시 관련 이용약관 적용 범위 질의**

안녕하세요. KRX Data Marketplace 오픈API 서비스를 이용 중인 개인 개발자입니다.

오픈API 이용약관의 적용 범위에 관해 아래와 같이 서면으로 질의드리오니, 회신하여 주시면 감사하겠습니다.

### 1. 서비스 개요

- **서비스 형태**: 모바일 애플리케이션 (전자공시(DART) 기반 공시 알림·기업정보 조회 서비스)
- **이용 데이터**: 오픈API로 제공되는 유가증권·코스닥 종목 일별 시세(일봉), KOSPI·KOSDAQ 지수 일별 시세, ETF 일별 시세, 종목 기본정보
- **표시 방식**: 앱 내 기업 상세 화면에서 일봉 차트·지수 추이 등으로 표시하며, 화면에 "자료 출처: 한국거래소" 출처 표기를 병기함
- **과금 여부**: 현재 **전면 무료** 서비스이며, 데이터 이용에 대한 대가를 이용자에게 청구하지 않음
- **데이터 가공**: 원데이터의 수치를 변형하지 않으며, 차트 시각화 등 표시 형태의 가공만 수행함
- **원데이터 파일 제공 여부**: 이용자가 원데이터를 파일 등으로 내려받는 기능은 제공하지 않음(화면 표시 한정)

### 2. 질의 사항

**질의 1. 무료 앱 내 표시의 허용 여부**

이용약관 제11조 제2항은 "API 이용자는 한국거래소로부터 제공받은 정보를 제3자에게 제공할 수 없다"고 규정하고 있습니다.
위 1항과 같이 **무료 앱에서 일봉·지수 데이터를 출처 표기와 함께 화면에 표시**하는 것이
동 조항의 "제3자 제공"에 해당하여 금지되는지, 또는 비상업·출처표기·화면표시 한정 등의 조건 하에
허용되는 이용 형태인지 확인을 부탁드립니다.

**질의 2. 유료화 시의 조건**

향후 서비스 일부를 유료(구독 등)로 전환할 경우,

- (a) 오픈API 데이터를 유료 서비스 영역에 포함하는 것은 이용약관 제6조 제2항(비상업적 목적 한정)상 불가한 것으로 이해하면 되는지,
- (b) 불가하다면, 유료 서비스에서 시세 데이터를 적법하게 표시하기 위해 체결해야 하는 계약(KRX 시세정보 이용계약, 코스콤 경유 계약 등)의 종류와 절차, 대략적인 비용 기준을 안내받을 수 있는지

확인을 부탁드립니다.

**질의 3. 내부 분석 목적 이용의 허용 범위**

이용자 화면에 표시하지 않고 **서버 내부의 통계 분석(과거 수익률 분석 등) 용도로만** 오픈API 데이터를
수집·보관하는 것은 약관상 허용되는 이용 형태인지 확인을 부탁드립니다.

**질의 4. 출처 표기 방식**

허용되는 이용 범위 내에서 데이터를 표시할 때 요구되는 출처 표기의 문구·형식 기준이 있다면 안내를 부탁드립니다.
(현재 "자료 출처: 한국거래소"로 표기 중)
