# DART 공시 유형 분류 체계

> 최종 수정일: 2026-03-08

## 1. DART 공식 공시 유형 (pblntf_ty)

DART OpenAPI `/list.json` 요청 시 `pblntf_ty` 파라미터로 공시 유형을 필터링할 수 있다.

| 코드 | 공시 유형 | 설명 |
|------|----------|------|
| A | 정기공시 | 사업보고서, 반기보고서, 분기보고서 등 정기적으로 제출하는 공시 |
| B | 주요사항보고 | 주요사항보고서, 주요경영사항 등 기업의 중요한 변동사항 |
| C | 발행공시 | 증권신고서, 투자설명서 등 증권 발행 관련 공시 |
| D | 지분공시 | 주식등의 대량보유상황보고서, 임원·주요주주 소유상황보고서 등 |
| E | 기타공시 | 자기주식취득/처분, 공개매수, 합병, 분할 등 |
| F | 외부감사관련 | 외부감사 실시내용, 감사보고서 등 |
| G | 펀드공시 | 집합투자기구(펀드) 관련 공시 |
| H | 자산유동화 | 자산유동화증권 관련 공시 |
| I | 거래소공시 | 한국거래소에서 발표하는 공시 (상장폐지, 거래정지 등) |
| J | 공정위공시 | 공정거래위원회 관련 공시 (대규모 기업집단 등) |

> 참고: `pblntf_ty` 파라미터 미지정 시 전체 유형이 조회됨

## 3. 우리 앱의 분류 체계 (7분류)

DART의 10가지 공식 유형을 7가지로 재분류하여 사용.

### 분류 매핑

| 앱 분류 | DART 유형 | 보고서명 매칭 키워드 | 색상 | Hex |
|---------|----------|-------------------|------|-----|
| **정기공시** | A | 사업보고서, 반기보고서, 분기보고서 | 파랑 | `#2563EB` |
| **주요사항보고** | B | 주요사항보고, 자산양수도, 영업양수도, 합병, 분할, 해산사유, 주식교환, 주식이전 | 빨강 | `#DC2626` |
| **발행공시** | C | 증권신고서, 투자설명서, 증권발행실적, 소액공모, 채권발행 | 주황 | `#D97706` |
| **지분공시** | D | 대량보유, 소유상황, 공개매수, 의결권대리행사, 주식등의 | 보라 | `#7C3AED` |
| **감사공시** | F | 감사보고서, 외부감사, 내부회계, 회계감사 | 틸 | `#0D9488` |
| **거래소공시** | I | 거래소, 상장폐지, 거래정지, 투자주의, 시장조치, 불성실공시, 조회공시 | 핑크 | `#DB2777` |
| **기타공시** | E, G, H, J | 위에 해당하지 않는 모든 공시 | 회색 | `#6B7280` |

### 분류 로직 위치

- **백엔드 분류 함수**: `backend/src/dart-api/dart-api.service.ts` → `classifyDisclosureType()`
- **프론트엔드 색상**: `mobile/utils/disclosureType.ts`
- **사용자 알림 설정**: `NotificationSettings.disclosureTypes` (String[])

### 분류 방식

보고서명(`report_nm`)에 대한 정규식 패턴 매칭으로 분류한다.

```typescript
classifyDisclosureType(reportName: string): string
// 예: "주요사항보고서(회생절차개시신청)" → "주요사항보고"
// 예: "감사보고서" → "감사공시"
// 예: "[기재정정]거래소 관련 공시" → "거래소공시"
```

## 4. 주요 보고서 유형 상세

### 정기공시 (Regular Reporting)
| 보고서명 | 제출 시기 | 중요도 |
|---------|----------|--------|
| 사업보고서 | 사업연도 종료 후 90일 이내 | 높음 |
| 반기보고서 | 반기 종료 후 45일 이내 | 중간 |
| 분기보고서 | 분기 종료 후 45일 이내 | 중간 |

### 주요사항보고 (Major Events)
| 보고서명 | 내용 | 중요도 |
|---------|------|--------|
| 주요사항보고서 | 회생절차, 파산, 영업정지, 대규모 손해 등 | 매우 높음 |
| 자산양수도 결정 | 대규모 자산의 매매 | 높음 |
| 영업양수도 결정 | 사업부문 매각/인수 | 높음 |
| 합병/분할 결정 | 법인 구조 변경 | 높음 |
| 주식교환/이전 결정 | 지주회사 전환 등 | 높음 |

### 발행공시 (Securities Issuance)
| 보고서명 | 내용 | 중요도 |
|---------|------|--------|
| 증권신고서 | 주식, 채권 등 증권 발행 신고 | 높음 |
| 투자설명서 | 투자자를 위한 상세 설명 자료 | 중간 |
| 소액공모 | 소규모 공모 관련 | 낮음 |
| 채권발행실적보고서 | 채권 발행 결과 | 중간 |

### 지분공시 (Shareholding)
| 보고서명 | 내용 | 중요도 |
|---------|------|--------|
| 주식등의대량보유상황보고서 | 5% 이상 지분 보유/변동 | 높음 |
| 임원·주요주주소유상황보고서 | 내부자 지분 변동 | 높음 |
| 공개매수신고서 | 공개매수 실시 | 높음 |

### 감사공시 (Audit)
| 보고서명 | 내용 | 중요도 |
|---------|------|--------|
| 감사보고서 | 외부감사인의 재무제표 감사 결과 | 높음 |
| 외부감사 실시내용 | 감사 진행 상황 | 중간 |
| 내부회계관리제도 | 내부통제 관련 보고 | 중간 |

### 거래소공시 (Exchange)
| 보고서명 | 내용 | 중요도 |
|---------|------|--------|
| 상장폐지 관련 | 상장폐지 사유 발생/결정 | 매우 높음 |
| 거래정지 | 매매거래 정지 | 매우 높음 |
| 투자주의/경고 | 투자 위험 안내 | 높음 |
| 불성실공시법인 지정 | 공시 의무 위반 | 중간 |
| 조회공시 | 거래소의 정보 확인 요청에 대한 답변 | 중간 |

### 기타공시
| 보고서명 | 내용 |
|---------|------|
| 자기주식취득/처분 | 자사주 매매 |
| 집합투자기구(펀드) 관련 | 펀드 설정/해지/변경 |
| 자산유동화 관련 | ABS 발행 등 |
| 공정거래위원회 관련 | 대규모 기업집단 지정 등 |

## 5. 분류의 한계

DART API는 **공시 서류의 행정적 유형**만 분류하며, 아래와 같은 **투자 목적/대상별 분류는 제공하지 않는다.**

| 분류 불가능한 항목 | 이유 |
|------------------|------|
| 외국인 투자 | 공시 본문 안에만 포함. 메타데이터에 없음 |
| 시설 투자 | 주요사항보고서 본문에 포함. 보고서명에 힌트가 있을 수 있으나 일관되지 않음 |
| 업종별 분류 | DART API에 업종 필드 없음 (별도 기업개황 API로 조회 가능) |
| 투자 규모/금액 | 공시 본문 파싱 필요 |
| 긍정/부정 이슈 | 자연어 분석 필요 (예: 실적 개선 vs 적자 전환) |

이런 세부 분류가 필요할 경우:
1. **보고서명 키워드 세분화** - `출자증권`, `타법인`, `시설투자` 등 추가 패턴 매칭 (제한적)
2. **DART 본문 크롤링** - API가 아닌 웹 스크래핑으로 본문 내용 파싱 (법적/기술적 부담)
3. **기업개황 API 연동** - `corp_code`로 업종, 대표자, 설립일 등 추가 정보 조회 가능

## 6. 향후 개선 고려사항

- [ ] `pblntf_ty` 파라미터 활용하여 DART API 레벨에서 유형별 조회 (현재는 보고서명 기반 분류)
- [ ] 기타공시 세분화 (펀드공시, 자산유동화, 공정위공시 분리 여부)
- [ ] `corp_cls`(기업분류) 기반 필터 추가 (코스피/코스닥/코넥스)
- [ ] 사용자별 관심 공시 유형 세분화 설정
- [ ] 공시 중요도 자동 판별 로직 추가
- [ ] 보고서명 키워드 확장으로 세부 주제 태깅 (시설투자, M&A, 유상증자 등)
- [ ] 기업개황 API 연동하여 업종 정보 부가
