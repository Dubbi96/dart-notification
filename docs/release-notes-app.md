# 모바일 앱 릴리스 노트

사용자 배포(EAS Update/빌드) 시 참고할 앱 변경 이력. 각 항목은 **무엇이 바뀌었는지**와
**확인 방법**(QA·릴리스 노트 작성자가 실제 앱에서 검증하는 절차)을 함께 적는다.

## 미출시 (Unreleased)

### 예정 이벤트 캘린더 — 전체 화면 (DAR-541)

- 홈 '예정 이벤트' 섹션(가까운 5건)에서 **전체 보기**로 진입하는 전용 화면을 추가했다.
  관심기업 공시에서 확인된 예정 일정(유상증자 청약일·신주 상장 예정일·배당 기준일 등)을
  D-day 오름차순으로 **전부**(서버 90일 윈도) 보여준다. 오늘/임박(0~3일) 일정은 D-day 칩이
  강조 톤으로 표시되고, 각 행을 탭하면 근거 공시 원문으로 바로 이동해 날짜를 검증할 수 있다.
- 정직 규약(계승): 서버가 추출이 확실한 날짜만 내려주므로, 없으면 수치를 지어내지 않고
  '예정된 이벤트가 없어요' 빈 상태를 보여준다. 게스트는 로그인 유도 화면을 본다.

**확인 방법**

1. 관심기업이 1개 이상 있고, 그 기업 공시에 예정 일정(예: 유상증자 청약일)이 있는 계정으로 로그인한다.
2. 홈 화면 하단 '예정 이벤트' 섹션 헤딩 우측의 **전체 보기**를 탭한다 → 전용 화면으로 이동.
3. 목록이 **D-day 가까운 순**으로 정렬되고, 오늘(D-Day)·임박(D-1~D-3) 항목의 칩이 강조 톤인지 확인한다.
4. 아무 행이나 탭 → 해당 **공시 상세**(원문)로 이동하는지 확인한다(딥링크).
5. 관심기업이 없거나 예정 일정이 없는 계정에서는 홈 섹션 자체가 보이지 않고, 화면을 직접 열면
   '예정된 이벤트가 없어요' 빈 상태가 나오는지 확인한다(빈 백지·가짜 날짜 없음).
6. 목록을 아래로 당겨 새로고침(pull-to-refresh)이 동작하는지 확인한다.

> 회귀 안전: 순수 표시/네비게이션 추가(신규 서버 계약 없음, BE 무변경). 홈 섹션은 DAR-538 대비
> '전체 보기' 진입만 추가됐고 행 표기는 공유 컴포넌트로 동일하다.
