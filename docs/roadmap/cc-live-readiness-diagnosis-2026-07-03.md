## 0. 한 줄 결론

> **"룰은 대체로 무죄, 측정과 배선이 유죄."** Track B 불합격의 간판 증거였던 'BLOCKED 역예측'은 3중 측정 오염으로 판명됐고(§2), 사용자가 지적한 트랙 구조·장외 매매도 모두 실결함으로 확정됐다(§1). 실투자 전환의 경로는 명확하다: **측정층 수정 → 재검증 2회차 → 트랙 forward 병렬 검증 → M10 졸업(≈7/21) → KIS 모의 램프업 → 소액 실전.** 코드가 막는 것은 1차 웨이브로 지금 고치고 있고, 나머지는 캘린더와 사용자 준비물이다.

## 4. 1차 고도화 백로그 — 지금 착수 가능 (wave1 = 구현 진행 중)

**Wave 1 (백엔드, ✅ 구현 완료 — 본 브랜치)**: ①체결 의미론(§1-②) ②트랙 forward 배선(§1-①) ③측정층 TB-1/2/3 ④파싱→추출 체이닝 복원(DQ-1) ⑤킬스위치 SELL 게이트(GAP-11) ⑥compose 하드닝+백업 스크립트(OPS-1·3)
**Wave 2 (모바일, ✅ 구현 완료 — 본 브랜치)**: ⑦카드 크기·표본 표시 수정(§1-③) ⑧정확도 화면 median 1차 표기(TRUST-02) ⑨신호 탭 코치마크(W1 잔여) ⑩auto-trading 고지 1줄 ⑪재검증 상태 뱃지(CONF-02 반영 — 수치는 2회차 확정값만)
**Wave 3 (후속 이슈화)**: DQ-2 수치추출 SUCCESS율(NO_PARSED_FIELD 분해), DQ-5 거래대상 드레인 상시화(쿼터 예산 내), OPS-2 알림 경로(단기: 외부 폴러 무료), OPS-4 감사로그 DB 강제, MISS-02 정정공시 무효화, MISS-01 운영자 가드, TRUST-03 표본 드릴다운, GAP-15 체결모델 보정(배포는 §8-1 결정 후)

## 8. 결정 필요 사항 (사용자)

1. **M10 측정 동결 vs 수정 즉시 배포 (CONF-01)** — 체결 의미론 수정은 편향 제거(정직화)지만 30일 윈도 중간의 레짐 변경. 선택지: (a) 즉시 배포 + 졸업 측정을 수정 이후 구간으로 재기산(클록 리셋, 권장 — 편향 위 졸업은 거짓 졸업) (b) 7/21까지 동결 + 수정판은 병렬 트랙으로만. **권장 (a)**.
