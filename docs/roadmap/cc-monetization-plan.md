## 1. 원칙: 무엇을 팔고, 무엇을 팔지 않는가

1. **알림 + 요약 = 무료 기준선.** 공시 알림·기본 요약은 무료로 유지한다(경쟁력 기준선, 갭분석 상용화 게이트 소견과 정합).
2. **v1 유료 = '도구 편의' 한정.** 무제한(대용량) 관심기업·고급 필터·심화 분석·우선 알림 등 *편의성* 기능만 과금한다. 종목 추천성 표면(Buy Score·매매 신호)은 유료 티어에서 **배제**한다.
3. **신호 판매는 봉인.** 매매 신호·추천의 유료화는 (a) 엣지 재검증 통과 **그리고** (b) 유사투자자문업 신고 완료 — 두 조건이 모두 충족되기 전에는 금지한다. 현재 Track B 재검증 불합격(M11 보류) 상태에서 신호 과금은 순서 역행이다.
4. **검증 전 고정비 0.** PG 계약·스토어 등록 등 현금/의무가 발생하는 단계는 전부 수요 게이트(waitlist·파일럿) 뒤에 둔다.
5. **M10 무오염.** 수익화 레이어(tier 게이트·계측·문서)는 컨트롤러·모바일 레이어에 한정하고 5엔진(신호·모의체결 경로)에 무접촉한다. 위반 시 M10 졸업 측정이 무효가 된다.

## 3. 가격 가설 (2안) — 최종 결정: 오너

경쟁사 실증 가격대(카테고리 지불의사 증명): 라씨 매매비서 월 약 8만원(2026.5 구글 플레이 금융 부문 최고 매출 1위), 알파스퀘어 월 1.98만~6.99만원 3단 멤버십, 와이즈리포트 월 11만원. **경쟁 밴드 하단(2만원) 아래로 침투**하는 저가 전략을 취한다 — 우리 v1 유료는 신호가 아닌 '도구 편의'라 고가 정당화 근거가 없고, 초기 전환율 데이터 확보가 우선이기 때문이다.

| 가설 | 월 가격 | 논거 | 리스크 |
|---|---|---|---|
| A안 | **₩9,900** | 심리적 1만원 미만 — 전환율 극대화, 파일럿 표본 확보 속도 우선 | 저가 앵커 고착 — 이후 인상 저항 |
| B안 | **₩14,900** | 라씨(≈8만)·알파스퀘어(≈2만~) 하단 대비 여전히 침투가이면서 ARPU 1.5배 | 무료 기준선 대비 가치 입증 부담 증가 |

- 연간 결제 할인(예: 2개월 무료)은 가격 확정 후 별도 결정.
- **가격 최종 결정 = 오너 항목.** 이 문서는 가설 2안과 논거만 제공한다. `cc-resume-plan-2026-07-02.md` §4-4의 "사용자 결정 대기" 상태를 이 문서로 해소하되, 결정 자체는 waitlist 전환율·유료 파일럿(§5 레일A 게이트) 데이터가 모인 뒤 오너가 내린다.
- 결정 기록란: `가격 확정: ____ (결정일: ____, 결정자: 오너)`

## 4. 규제 결정트리 — 유사투자자문업 신고 vs 비자문 도구 과금

```
과금하려는 기능이 '투자판단 조언·신호·추천'을 포함하는가?
├─ 아니오 (무제한 관심기업·고급필터·히스토리·우선알림 = 도구 편의)
│   → 비자문 도구 과금: 신고 불요. v1 유료는 이 경로만 사용.
│   → 단, Buy Score가 화면에 상존하는 앱 특성상 논란 여지 있음:
│      · 유료 기능에서 종목 추천성 표면 배제 (유료 게이트가 신호 노출을 확대하지 않게)
│      · plan-policy.md 비자문 고지 문구를 결제 플로우에 필수 삽입
│      · 애매하면 신고를 선제 이행 (신고 자체는 무료 신고제)
└─ 예 (매매 신호·추천 판매)
    → 봉인. 해제 조건 2가지 모두 충족 시에만 재개:
       ① 엣지 재검증 통과 (현재 Track B 불합격 → M11 보류 중)
       ② 유사투자자문업 신고 완료 (금감원 신고제 + 사업자등록 + 금융소비자보호 교육 이수)
    → 조건 미충족 상태의 신호 과금은 규제 리스크 + 검증 안 된 상품 판매 이중 문제.
       '해결하지 않고 우회'가 정당하다.
```

- 조건부 비용: 유사투자자문업 신고는 무료이나 사업자등록 + 교육 이수가 따라온다 — 신호 판매를 봉인하는 한 발생하지 않는다.
- PG 직접 계약(포트원/토스페이먼츠) 경로도 사업자등록 필수 + 건당 ~3% 수수료 + 부가세 신고 의무 발생 → §5 게이트 통과 전 계약 금지(고정비 0 유지).

## 7. M10.5 "MZ. 수익화 토대" 트랙 제안

`01-execution-roadmap.md`에 M10 졸업 게이트와 M11 사이 **'MZ. 수익화 토대'(가칭 M10.5)** 트랙 신설을 제안한다.

**근거 3가지:**
1. **유휴 공백의 최적 충전재** — M11은 Track B 재검증 불합격으로 보류 확정. M10 캘린더 시간(30일 무인 누적, 졸업측정 ~8월 초) 동안 에이전트 플릿이 유휴 상태가 되는데, 수익화 레이어가 이 공백을 채운다.
2. **M10 오염 0으로 병행 가능** — 수익화 레이어는 API·모바일·문서만 건드려 5엔진 무접촉. 퀵윈(waitlist 계측·SSOT 문서·tier 소켓)은 졸업 전 즉시, 기능 게이트 end-to-end는 졸업 직후 착수.
3. **순서 충돌 없음** — M11(실주문)은 어차피 '검증된 엣지' 전제라 수익화가 선행되어도 충돌하지 않는다. 또한 **M13A(미국주식 확장)보다 MZ가 선행**되어야 한다 — 매출 0 상태에서 자산군 확장은 비용만 늘린다.

**MZ 스코프(안):**

| 구분 | 항목 | 시점 |
|---|---|---|
| 완료 | 서버측 waitlist 계측(`ProWaitlistEntry`) · 본 SSOT 문서 · `User.tier` 소켓 + 관심기업 30/200 tier 한도 | 졸업 전 (완료) |
