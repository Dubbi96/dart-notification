# 신호·포트폴리오 화면 UX 재설계 스펙

## 1. 핵심 진단 요약 — 현재의 "정보 난무"

현재 신호 탭(`app/(tabs)/signals/index.tsx`)은 recommend-first 관점에서 가장 취약하다. 진입 즉시 **메타 진입점 배너 2개(투자거장·이벤트 통계)가 상단을 잠식**한 뒤, `useBuySignals()` 결과를 **정렬·큐레이션 없이 원순서 풀피드로** 쏟는다. 즉 "추천"과 "전체 목록"이 화면상 구분되지 않는다.

실제 추천 큐레이션 로직(상위 N·점수 내림차순·BUY/STRONG_BUY만·가짜 BUY 금지)은 `HomeSignalPreview.tsx`에만 존재해 신호 탭과 단절돼 있고, **종목별 검색 진입점은 신호 탭에 아예 없다**(SearchOverlay는 기업검색·watchlist 전용). progressive disclosure의 핵심 도구인 `SignalExplorer.tsx`는 구현돼 있으나 `app/` 어디에도 마운트되지 않은 **고아 컴포넌트**다.

카드 단위도 과적층이다. `BuyScoreCard`는 한 카드에 9개 요소(등급칩·티커·eventType 평문·RiskStatusBadges·게이지·AI요약 3줄·진입조건 3행·riskFlag·AI라벨)를 쌓아 **카드 하나가 미니 상세 화면**이 되었고, eventType은 헤더 칩과 서브헤더에 2회, 위험정보는 RiskStatusBadges와 riskFlags[0]로 2채널 중복 노출된다. 결과적으로 화면 위계가 "메타 배너 2개 → 정렬없는 풀피드 → 지표 난무 카드"로 무너져, **추천도 검색도 드릴다운도 성립하지 않는다.**

## 2. 앱 전역 패턴: "추천 우선 → 검색/필터 → 드릴다운"

세 계층을 모든 데이터 화면(신호·포트폴리오)의 공통 골격으로 강제한다. 진입 시 사용자는 항상 **좁고 신뢰 가능한 큐레이션**을 먼저 보고, 필요할 때만 아래로 파고든다.

| 계층 | 역할 | 노출 정보 밀도 | 신뢰 장치 |
|---|---|---|---|
| **L1 추천 우선** | 진입 즉시 "오늘 주목할 N건" 큐레이션. 방대한 리스트 금지 | 카드당 3~4요소 + 추천 이유 1줄 | 큐레이션 기준 라벨('점수순 상위'), 표본/면책, 위험배지 |
| **L2 검색·필터** | 종목명/티커 검색 + 등급·성향·이벤트 필터·정렬 | 결과 건수 + 압축 카드 | 빈 결과 정직 안내, 필터 초기화 |
| **L3 드릴다운 상세** | 단일 종목/신호의 전체 근거 | 전체 지표(접기/탭으로 위계화) | Score 분해, 출처/시점, severity, 데이터 한계 |

**핵심 규칙:** (1) L1은 절대 전체 피드가 아니다 — 상위 큐레이션만. (2) "왜 추천됐는가" 1줄 근거가 L1 카드의 신뢰 핵심. (3) 한 화면에 모든 지표를 평면 나열하지 않는다 — 지표는 L3에서 탭/접기로 위계화. (4) 표본 0·미유의 등 데이터 한계는 숨기지 않고 배지로 정직 노출.

**신호 적용:** L1 = 오늘 주목 신호 큐레이션 슬롯 / L2 = 종목 검색 + SignalExplorer 마운트 / L3 = `/signals/[id]`.
**포트폴리오 적용:** L1 = 오늘 점검할 포지션(매도시급·논거훼손 상위) / L2 = 보유종목 검색·정렬 / L3 = 포지션 상세 + 성과·정밀도·보정 탭.

## 3. 신호 화면 재설계

### (a) 진입 시 추천 우선 (L1)

- **신설: "오늘 주목할 신호" 큐레이션 헤더 슬롯** — 화면 최상단 1순위. `HomeSignalPreview`의 큐레이션 로직(BUY_GRADES 필터 → buyScore 내림차순 → 상위 3~5건, 가짜 BUY 금지)을 신호 탭으로 이식·승격. 매수/매도 통합 상위 3~5건을 가로 카루셀로.
- **추천 카드 = 핵심 4요소만**: 기업명 + 이벤트유형 칩 + 등급 칩(gradeLabel) + Buy Score 게이지(ScoreGauge).
- **추천 이유 1줄(scoreOneLiner) 노출** — 현재 oneLiner는 상세에만 존재. recommend-first에선 "왜 추천됐는가" 한 줄이 신뢰의 핵심이므로 L1 카드로 끌어온다.
- **큐레이션 기준 라벨** — "공시 기반 점수순 상위" 같은 라벨로 정렬 근거 명시(블랙박스·과신 방지).
- **RiskStatusBadges(관리종목·거래정지·상폐위험) 즉시 노출 유지** — 추천을 먼저 보여주되 위험은 숨기지 않는다(손실회피 1차 방어선).
- **BLOCKED 차단 사유 박스 유지** — 게이지 대체로, "왜 추천 안 되는지" 즉시 전달.

### (b) 종목별 검색 동선 (L2)

- **신설: 신호 탭 검색 입력** — 큐레이션 슬롯 바로 아래 TextInput(placeholder "종목명·티커 검색"). 기존 SearchOverlay를 신호 컨텍스트로 확장하거나 신호 전용 검색 진입 추가. "OOO 종목의 매수·매도 신호 보기" 동선 확보(사용자 방향 2번 충족).
- **SignalExplorer 정식 마운트** — 고아 컴포넌트를 검색/필터 계층으로 신호 탭에 마운트. 등급·투자성향·이벤트유형 필터 칩 + 정렬 칩 + 결과 건수 + 무한스크롤. 추천→필터/검색→상세의 **중간 계층 복원**.
- **매수/매도 SegmentedButtons는 전체 피드 드릴다운의 입구로 유지** — 단, 추천 슬롯·검색 영역 **아래** 위계로.

### (c) 드릴다운으로 미룰 것 (L3 `/signals/[id]`)

- 진입 조건 체크리스트 전체 → 카드엔 요약("진입조건 2/3 충족")만, 전체는 상세 진입 조건 섹션.
- AI 요약 3줄 → 카드에선 1줄 또는 제거, 상세 "AI 매수 근거 섹션"으로.
- riskFlags 전체 + severity → 카드엔 개수 배지("리스크 2")만, 전체는 상세 리스크 섹션.
- ScoreBreakdownSection / EvidenceMeta(표본 N건) → 상세 전용 유지(현재 올바름).
- ExitScoreCard의 reasonList·recommendedAction·blockRebuy·pnlPercent → 매도 서브탭/상세로.

### (d) 제거/축소할 노이즈

- **상단 배너 2개(투자거장·이벤트 통계)** → 추천 슬롯보다 먼저 와서 추천을 밀어냄. 피드 하단 또는 별도 "탐색" 진입으로 위계 하향.
- **eventType 라벨 중복**(헤더 칩 + 서브헤더 2회) → 한 곳으로 통합.
- **위험 정보 2채널 중복**(RiskStatusBadges + riskFlags[0]) → RiskStatusBadges로 단일화, riskFlags는 상세로.
- **AiReferenceLabel 카드마다 반복** → 면책은 필수지만 리스트 전체 반복은 소음. 피드 1회(푸터 DisclaimerSection)로 충분, 카드별 반복 축소.
- **정렬·큐레이션 없는 풀피드** → L1 큐레이션과 L2 전체 탐색을 명확히 분리.

### (e) 추가 필요

- 신호 탭 전용 큐레이션 헤더 슬롯(상위 N·점수순·근거 1줄).
- 종목 검색 입력/버튼.
- SignalExplorer 진입로(탭 내 정식 배치 또는 "전체 신호 탐색" 진입).
- 추천 0건일 때 "점수순 전체 탐색" CTA(현재 신호 탭 빈 상태는 관심기업 추가만 유도 — 탐색 유도 약함).

## 4. 포트폴리오 화면 재설계

동일 골격(L1 추천 우선 → L2 검색/필터 → L3 드릴다운)을 적용한다. 포트폴리오의 핵심 문제는 **매매성적표·신호정밀도·보정권고가 한 화면에 평면 나열**돼 지표가 난무하는 것이다. 이 셋을 위계화·접기·탭으로 정리한다.

### (a) 진입 시 추천 우선 (L1)

- **신설: "오늘 점검할 포지션" 큐레이션 슬롯** — 보유 포지션 중 **매도 시급도(Exit Score) 상위 / 논거 훼손 / 손절 임박** 3~5건만 먼저. 전체 보유목록을 쏟지 않는다.
- 포지션 추천 카드 = 핵심 4요소: 종목명 + 현재 손익률(pnlPercent) + Exit Score 게이지 + 권장 액션 칩.
- 점검 이유 1줄("논거 훼손: 매출 가이던스 하향") 노출.

### (b) 검색/필터 (L2)

- 보유종목 검색 입력(종목명·티커) + 정렬(손익순/시급도순/비중순).
- 전체 보유목록은 이 계층에서 압축 카드로.

### (c) 매매성적표·신호정밀도·보정권고 정리안 (L3 — 탭 분리)

세 지표군을 **포트폴리오 상세 하위 탭**으로 분리해, 진입 화면이 지표로 뒤덮이지 않게 한다.

| 지표군 | 현재 문제 | 재배치 |
|---|---|---|
| **매매성적표**(누적 수익률·승률·실현손익) | 진입 화면 상단을 차지, 일별 변동을 매번 강조 | L3 "성과" 탭으로 이동. L1에는 **요약 1행**(기간 수익률 + 추이 스파크라인)만 접어서 노출 |
| **신호정밀도**(신호 적중률·신뢰구간·표본) | 통계 메트릭이 카드마다 난무 | L3 "신호 정밀도" 탭. 표본<30·미유의 시 **'데이터 한계' 배지** 동반. 진입 화면 비노출 |
| **보정권고**(가중치 조정·리밸런싱 제안) | 행동 유도가 정보와 뒤섞임 | L3 "보정 권고" 탭 또는 L1 상단 **단일 권고 배너 1건**(가장 시급한 1개만). 나머지는 탭에서 |

**정리 원칙:** L1에는 "지금 행동해야 할 것" 1~2개만 / 성적표는 요약 1행 접기 / 정밀도·보정 전체는 L3 탭으로 미룬다. "지표 난무"를 위계+접기+탭 3단으로 해소.

### (d) 제거/축소할 노이즈

- 진입 화면의 성적표 풀 메트릭 패널 → 요약 1행으로 축소.
- 카드마다 반복되는 정밀도 통계 → 상세 탭으로 일괄 이전.
- 보정권고 다건 동시 노출 → 가장 시급한 1건만 L1, 나머지 탭.

### (e) 추가 필요

- "오늘 점검할 포지션" 큐레이션 로직(Exit Score·논거훼손 상위).
- 보유종목 검색·정렬.
- 성과/정밀도/보정 3탭 구조.
- 보유 0건 정직 빈 상태("관심종목 신호부터 시작" CTA).

## 6. 데이터 한계 정직 노출·신뢰 원칙

Main Thesis(정보수집 극대화 + 실제수익)와 신뢰 원칙(과신·FOMO 금지·출처·면책)을 UX에 다음과 같이 반영한다.

- **표본 한계 배지 상시화**: 표본<30 또는 통계 미유의(`totalSample<30 OR !isSignificant`) 시 '데이터 한계'(alert-triangle) 배지를 신호 상세·이벤트 통계·포트폴리오 정밀도 탭에 일관 노출. 표본 0건은 점수를 가짜로 만들지 않고 "표본 대기" 빈 상태로 정직 처리.
- **가짜 BUY 금지 원칙 유지**: 매수 등급 0건이면 L1에서 추천을 지어내지 않고 "점수순 전체 탐색" CTA로 유도(현재 HomeSignalPreview 정직 빈 상태 패턴을 신호 탭·포트폴리오로 확장).
- **출처·시점 명시**: 신호 상세의 ProvenanceBar(AI 분석 생성 시점)·관련 공시 직결 링크·RiskStatusBadges의 "DART 근사값" 표기를 유지·강화. 추천일수록 원천 공시로 1탭 이동 가능해야 신뢰가 성립.
- **큐레이션 기준 투명화**: L1 추천 슬롯에 정렬·선별 기준 라벨("공시 기반 점수순 상위") 노출 — 사용자가 "왜 이 순서인지" 알 수 있게 해 과신·블랙박스를 방지.

- **FOMO 억제**: L1을 "상위 N건"으로 좁히고 시급성 과장 카피를 배제. "오늘 주목/점검" 프레이밍으로 점검을 유도하되 매수 압박 톤을 피한다.
