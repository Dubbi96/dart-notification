# 역할별 업무 분산 & 책임 매트릭스

> 상위 문서: [비전](../00-vision-and-principles.md) · [실행 로드맵](../01-execution-roadmap.md) · 작성: 직접 판단

이 폴더는 [실행 로드맵](../01-execution-roadmap.md)의 마일스톤(M0~M12) 업무를 **역할(파트)별로 분산**한 문서 모음이다.
각 파트는 자기 문서를 열어 "내가 어느 마일스톤에서 무엇을 하는지"를 본다. 이 README는 그 위에서 **누가 주담당이고 누가 협업인지**를 한눈에 보여주는 책임 매트릭스다.

## 읽는 법

- **개발 파트(BE/FE/DQ/AI)** 는 자기 문서의 "마일스톤별 업무"에서 구현 작업을, "인터페이스/핸드오프"에서 다른 파트와 주고받는 계약을 본다.
- **기획 파트(화면/시나리오/정책)** 는 개발보다 **앞서** 산출물을 내야 하는 마일스톤(예: M6 매수 카드 → 화면·시나리오 기획이 FE 구현 전에 확정)에 유의한다.
- **QA·인프라** 는 거의 모든 마일스톤에 걸쳐 관여한다. 특히 QA는 [실행 로드맵](../01-execution-roadmap.md)의 회귀 체크포인트(↩︎)를 게이트로 운영한다.

## 공통 원칙 (전 역할 적용)

1. **AI 금지영역** — 최종 주문 승인·손익 하드룰·포트폴리오 한도·주문 수량·리스크 우회는 AI가 결정하지 않는다. (BE는 코드로 차단, QA는 감사, 정책은 고지)
2. **매도·포트폴리오 우선 안전설계** — `PositionThesis`/`ExitSignal`이 핵심.
3. **자동매매는 최후** — 백테스트·모의투자 졸업 게이트 통과 전 실주문 금지.
4. **데이터 소스** — 시세·통계는 KRX 데이터마켓플레이스(공기업) 1차, 실시간/체결만 증권사 OpenAPI 보완.
