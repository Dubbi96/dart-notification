# RSI 매수/매도 전략 백테스트 검토 (2026-06-26)

> F5(전략 수익엣지 부재) 트랙 부속. 정본 baseline: `buy-logic-validation-baseline.md`.
> 결론 한 줄: **RSI 단독 매수/매도는 단순 보유(+61%)를 못 이기며, "거래당 엣지"는 자본제약·동시성에서 증발한다. 단독 신호 제품화 비추천 — 현 보조필터 설계 유지.**

## 동기
사용자 요청 — "RSI 기준 매수/매도를 검토". 현 시스템은 RSI(14)를 **보조 필터**로만 사용:
- 일봉 Buy Score(`chart.scorer`): `rsi14<70` +10, `rsi14>30` +10 (80점 중 20)
- 일봉 진입 게이트(`entry-condition`): 필수 `NOT_OVERBOUGHT rsi14<70`
- 분봉 단타: RSI 미사용(VWAP 돌파 + 고정 TP/SL)

즉 전형적 RSI 매매(과매도 매수·과매수 매도 = 평균회귀)는 미구현이라, **채택 전 백테스트로 먼저 비교**(F5 규율).

## 방법 (독립 리서치 스크립트 — 프로덕션 엔진 미변경)
- 데이터: dev DB `stock_daily_prices` 16년치에서 RSI(14) **직접 계산**(Wilder). 저장된 `technical_indicators.rsi14`는 51일치뿐이라 미사용.
- 유니버스: 기간 평균 거래대금 ≥10억 유동종목 **1,898개**, 2023~2026(약 3.5년).
- 체결: 신호 **다음날 시가**(lookahead 차단). 비용 **왕복 0.42%**(수수료+세금+슬리피지 근사).
- 포트폴리오: 최대 20동시·균등배분·복리(총수익·MDD 산출).
- 스크립트: `scratchpad/rsi-backtest.mjs` (+ `prices.csv` 추출).

## 핵심 발견
1. **거래당 기대값 ≠ 포트폴리오 수익.** 임계 전략은 거래당 +1.84%·PF 1.35로 가장 좋아 보이나 포트폴리오는 **−43%**. 과매도 신호가 **하락장에서 동시다발** → 20슬롯이 전부 "떨어지는 칼" → 동시손실·자본묶임. 거래당 엣지가 자본제약에서 증발.
2. **모멘텀**은 거래당 엣지 ~0이나 회전 빨라 +31%(자본효율) — 그래도 보유의 절반, MDD 37%.
3. **장세 편향**: 2023~2025 강세장 내내 +였다가 2026 전부 − → 강건한 엣지 아님(F5와 일치).
