## 3. 불가침 확인

- **point-in-time(lookahead 0)**: `ExtendedWindowReplayService.run` → `executeReplay` 는 DAR-385/DAR-544에서
  이미 검증된 point-in-time 러너를 재사용했을 뿐, 본 실행에서 코드 변경이 없어 lookahead 특성도 변경되지 않았다.
- **AI 금지영역 미침범**: engine5(Risk·주문·하드룰)·AI 평가 경로 어디에도 손대지 않았다 — 실행한 두 스크립트는
  engine3 `backtest/` 산하 read-only 측정 인프라(DAR-544 봉인)뿐이다.
- **영속 0**: 두 러너 모두 `BacktestRun`/`BacktestTrade`/`PaperTrade` 테이블에 쓰지 않는다(스크립트 자체 주석
  + 리포트의 `read-only` 노트로 재확인). 코드 변경 0 — 이 문서 추가가 유일한 diff.

## 4. 원본 DoD와의 갭 (참고)

원 이슈의 `GET /api/backtest/track-record`(총수익률·승률·매매횟수·**MDD**·**equity 곡선**·이벤트유형별 성과)는
`POST /api/backtest/replay` 의 **영속 경로**(`BacktestReplayService.run`, `BacktestRun`/`BacktestTrade` 기록)를
전제로 한다. PM 재정의는 이 영속 경로 실행을 스코프에서 제외하고 read-only 측정 인프라 실행으로 대체했으므로,
MDD·equity 곡선은 본 리포트의 산출물이 아니다(§4 참고 — 필요 시 별도 이슈로 영속 경로 실행을 다룰 것).
