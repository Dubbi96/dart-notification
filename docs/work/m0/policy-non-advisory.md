## 1. 서비스 범위 정의

### 목적

서비스가 제공하는 것과 제공하지 않는 것을 공개 고지 가능한 수준으로 명확히 한정한다.
M0 시점 기능(공시 알림·조회)을 기준선으로 삼고, 향후 단계 확장 시 이 항목을 갱신한다.

### 제공하는 것 (M0 기준)

| 기능 | 설명 |
|------|------|
| DART 공시 실시간 알림 | 금융감독원 DART에 공시된 문서를 수집하여 관심 기업 기준으로 푸시 알림 발송 |
| 공시 조회·검색 | 공시 목록, 상세 내용, 원문(WebView) 조회 |
| 관심 기업 관리 | 기업 검색·등록·삭제, 관심 목록 기반 알림 필터링 |
| 알림 설정 | 공시 유형(7종) · 키워드 · on/off 개인 설정 |
| 공시 북마크 | 관심 공시를 저장하고 재열람 |
| 기업 개황 | DART 기업개황 데이터(업종·대표·주소 등) 조회 |

### 제공하지 않는 것 (M0 시점 명시)

| 비제공 항목 | 사유 |
|------------|------|
| 투자 권유 · 매수/매도 추천 | 자본시장법상 투자자문업 해당 가능 — 이 서비스는 투자자문업자가 아님 |
| 목표 주가 · 적정가 제시 | 동상 |
| AI 공시 분석 리포트 | 후속 단계(M3)에서 도입 예정. 현재 미제공 |
| Buy Score · 매수 신호 | 후속 단계(M6)에서 도입 예정. 현재 미제공 |
| 시세 데이터 · 기술지표 | 후속 단계(M4)에서 도입 예정. 현재 미제공 |
| 모의투자 포트폴리오 | 후속 단계(M10)에서 도입 예정. 현재 미제공 |
| 실주문 · 반자동매매 | 후속 단계(M11)에서 도입 예정. 현재 미제공 |
| 자동매매 | 후속 단계(M12)에서 도입 예정. 현재 미제공 |

### 필수 고지 문구 방향 (예시 문안)

> 공시on은 금융감독원 DART에 공시된 정보를 수집·전달하는 공시 알림 서비스입니다.
> 본 서비스는 공시 정보를 **참고 목적**으로 제공하며, 투자 의사결정의 기준 또는 권유가 되지 않습니다.
> 현재 단계에서는 공시 알림·조회 기능만 제공되며, 매매 기능은 제공되지 않습니다.

### 노출 위치

| 위치 | 노출 방식 | 시점 |
|------|----------|------|
| 온보딩 화면 (최초 가입 후) | 팝업 1회 고지, 확인 버튼 | 최초 앱 진입 시 |
| 앱 설정 > 법적 고지 | 상시 접근 가능 텍스트 | 상시 |
| 공시 상세 화면 하단 | 소형 텍스트 주석 | 상시 |

## 2. 비투자자문 고지

### 목적

자본시장과 금융투자업에 관한 법률(자본시장법) 제12조(금융투자업 인가) 및 유사투자자문업 관련 조항의 경계를 준수하기 위해 이 서비스가 투자자문을 제공하지 않음을 명시적으로 고지한다.

**유의 경계선**
- 허용: 공시 내용을 요약·분류하여 제공 ("~공시가 접수되었습니다")
- 허용: 과거 통계 기반 참고 지표를 면책 문구와 함께 제시 (M6 이후 Buy Score 도입 시)
- 경계: 특정 종목 매수·매도를 직접 권유하는 문구 ("~종목을 매수하는 것이 좋겠습니다")
- 금지: 유사투자자문업 등록 없이 반복적·유상으로 투자 판단을 제공하는 행위

### 필수 고지 문구 방향 (예시 문안)

> **[비투자자문 고지]**
> 본 서비스는 「자본시장과 금융투자업에 관한 법률」상 투자자문업에 해당하지 않습니다.
> 서비스가 제공하는 공시 알림·분석 리포트·참고 지표는 투자 판단의 **참고 자료**로만 활용하시기 바랍니다.
> 특정 금융상품의 매수·매도를 권유하지 않으며, 최종 투자 결정과 그에 따른 손익은 전적으로 투자자 본인에게 있습니다.

### 노출 위치

| 위치 | 노출 방식 | 시점 |
|------|----------|------|
| 온보딩 (최초 1회) | 팝업 고지 → 확인 버튼 필수 | 최초 앱 진입 시 |
| 앱 설정 > 법적 고지 > 비투자자문 고지 | 상시 접근 가능 페이지 | 상시 |
| (M3 이후) AI 분석 리포트 화면 하단 | 소형 텍스트 주석, 상시 표시 | AI 기능 도입 시 |
| (M6 이후) Buy Score · 신호 카드 내 | 툴팁 또는 하단 주석 | 매수 신호 도입 시 |

### 기존 약관(terms.tsx) 연계

현행 `제8조 (면책조항)` ②항 내용과 일치: "서비스에서 제공하는 정보는 투자 판단의 참고 자료이며, 이를 근거로 한 투자 결과에 대해 서비스는 책임을 지지 않습니다."
→ 이 고지 항목은 기존 약관 제8조를 화면 노출 형태로 구체화한 것이며, 내용 일관성을 유지한다.

## 3. 투자 책임 면책 (손익·결과)

### 목적

서비스가 제공하는 정보를 기반으로 이용자가 투자 결정을 내린 경우 발생하는 손익에 대해 서비스 운영사가 책임을 부담하지 않음을 명확히 한다.

### 필수 고지 문구 방향 (예시 문안)

> **[투자 책임 고지]**
> 주식·채권 등 금융투자상품 투자는 원금 전액 손실이 발생할 수 있습니다.
> 본 서비스의 공시 정보, 분석 결과, 참고 지표를 바탕으로 내린 투자 결정과 그에 따른 손익(수익 및 손실)은 전적으로 투자자 본인에게 귀속됩니다.
> 서비스 운영사는 이용자의 투자 결과에 대해 어떠한 법적·재정적 책임도 부담하지 않습니다.

### 노출 위치

| 위치 | 노출 방식 | 시점 |
|------|----------|------|
| 온보딩 (최초 1회) | 비투자자문 고지 팝업에 포함 | 최초 앱 진입 시 |
| 앱 설정 > 법적 고지 | 상시 접근 페이지 | 상시 |
| 서비스 이용약관 제8조 | 법적 문서에 포함 | 약관 접근 시 |
| (M11 이후) 실매매 진입 동의서 | 체크박스 개별 항목 | 반자동매매 활성화 전 |

### 기존 약관(terms.tsx) 연계

현행 `제8조 (면책조항)` ②③항에 이미 반영됨:
- ②: "서비스에서 제공하는 정보는 투자 판단의 참고 자료이며, 이를 근거로 한 투자 결과에 대해 서비스는 책임을 지지 않습니다."
- ③: "이용자는 공시 원문을 직접 확인하여 투자 의사결정을 내려야 합니다."

→ M0 단계에서 별도 항목 추가 없이 기존 내용 유지. 다만 온보딩 팝업 노출 형태 추가가 필요하다(화면 기획 전달).

## 4. 데이터 출처 표기 원칙 (DART · KRX)

### 목적

외부 공공기관 데이터를 활용하는 서비스로서 데이터 출처를 투명하게 표기하고, 데이터 제공 기관의 이용 약관을 준수한다. 데이터 출처를 표기하지 않으면 저작권·이용 조건 위반이 발생할 수 있다.

### DART (금융감독원 전자공시시스템)

| 항목 | 내용 |
|------|------|
| 데이터 성격 | 금융감독원이 운영하는 공공 전자공시 시스템. DART OpenAPI를 통해 데이터 수집 |
| 이용 조건 | DART OpenAPI 이용약관 준수 필요. 공공데이터 성격이나 상업적 이용 허용 범위 확인 필요 |
| 출처 표기 의무 | 공시 원문 및 데이터 화면에 "출처: 금융감독원 전자공시시스템(DART)" 표기 |
| 저작권 | 현행 약관 `제9조 (지적재산권)` ②항에 명시: "DART 공시 원문의 저작권은 금융감독원 전자공시시스템에 있습니다." |

### KRX (한국거래소 데이터마켓플레이스)

| 항목 | 내용 |
|------|------|
| 데이터 성격 | 한국거래소(공기업)가 운영하는 시세·상장 데이터 플랫폼. M4 단계부터 사용 예정 |
| 이용 조건 | KRX 데이터마켓플레이스 라이선스 조건(유료 이용권, 재배포 금지, 출처 표기) 계약 전 확인 필요 |
| 출처 표기 의무 | 시세·지표 데이터 화면에 "시세 출처: 한국거래소" 또는 "데이터 제공: KRX 데이터마켓플레이스" 표기 |
| M0 단계 해당 여부 | KRX 데이터 미사용. M4 착수 전 라이선스 계약 및 출처 표기 정책 확정 필요 |

### 필수 고지 문구 방향 (예시 문안)

> **[데이터 출처]**
> 본 서비스의 공시 정보는 금융감독원 전자공시시스템(DART, dart.fss.or.kr)의 데이터를 활용합니다.
> 공시 원문의 저작권은 금융감독원에 있으며, 본 앱은 원문 조회 서비스를 제공할 뿐 원문의 편집·재배포를 하지 않습니다.
> (M4 이후 추가) 시세 데이터는 한국거래소(KRX) 데이터마켓플레이스를 통해 제공됩니다.

### 노출 위치

| 위치 | 노출 방식 | 시점 |
|------|----------|------|
| 앱 설정 > 법적 고지 > 데이터 출처 | 상시 접근 가능 텍스트 페이지 | 상시 (M0부터) |
| 공시 원문 뷰어(WebView) 하단 | 소형 텍스트 주석 | 공시 원문 조회 시 |
| (M4 이후) 시세·차트 화면 하단 | 소형 텍스트 주석 | 시세 기능 도입 시 |

## 5. 정보 정확성 면책

### 목적

DART 수집 과정의 오류, 공시 원문 파싱 한계, 데이터 지연 등으로 발생하는 정보 부정확성에 대해 서비스 운영사의 책임 범위를 명확히 한다.

### 면책 대상 및 사유

| 면책 대상 | 사유 |
|---------|------|
| 공시 수집 지연 | DART API 응답 지연, 수집 Cron 주기(장중 10분/장외 1시간)로 인한 최대 수십 분 지연 가능 |
| 공시 내용 오류 | DART 원문 데이터 자체 오류 또는 수정 공시(정정공시) 반영 지연 |
| (M1 이후) 파싱 오류 | HTML/XML 원문 구조 변경으로 파싱 실패 또는 오추출 가능 |
| (M3 이후) AI 분석 오류 | 외부 LLM API 특성상 동일 공시에 대해 상이한 해석 생성 가능, 이벤트 분류·긍부정 판단 오류 가능 |
| (M4 이후) 시세 지연 | KRX 데이터 수집 주기로 인한 지연, 실시간 체결가와 차이 가능 |

### 필수 고지 문구 방향 (예시 문안)

> **[정보 정확성 면책]**
> 본 서비스는 DART 공시 정보를 원본 그대로 제공하기 위해 노력하나, 다음과 같은 사유로 정보의 정확성·완전성·적시성을 보장하지 않습니다.
>
> • 공시 수집 주기로 인한 최신 공시 반영 지연 (최대 수십 분)
> • DART 원문 데이터의 오류 또는 정정 공시 반영 전 상태
> • 시스템 장애, 통신 오류 등 불가항력적 사유로 인한 서비스 일시 중단
>
> 이용자는 중요한 투자 결정 전 공시 원문을 DART(dart.fss.or.kr)에서 직접 확인하시기 바랍니다.

### 노출 위치

| 위치 | 노출 방식 | 시점 |
|------|----------|------|
| 온보딩 팝업 (비투자자문 고지와 통합 가능) | 팝업 고지 1회 | 최초 앱 진입 |
| 앱 설정 > 법적 고지 | 상시 접근 페이지 | 상시 |
| 서비스 이용약관 제8조 | 법적 문서 | 약관 접근 시 |
| 공시 상세 화면 하단 | 소형 텍스트 주석 | 공시 상세 조회 시 |

### 기존 약관(terms.tsx) 연계

현행 `제8조 (면책조항)` ①항과 일치: "서비스는 DART 공시 정보를 가공하여 제공하며, 정보의 정확성 및 완전성을 보장하지 않습니다."
→ 기존 내용 유지. 화면 노출 형태(공시 상세 하단 주석) 추가가 필요하다(화면 기획 전달).

## 6. 실매매 미제공 명시 (현재 단계)

### 목적

현재 서비스는 공시 알림·조회 기능만 제공하며 주식 매수·매도 주문 기능이 없음을 명확히 선언한다. 자동매매는 후속 단계(M11, M12)의 검증 게이트를 통과한 이후에만 도입 가능하며, 이 문서 작성 시점(M0)에는 실매매를 제공하지 않는다.

### 단계별 매매 기능 도입 계획

| 단계 | 기능 | 상태 |
|------|------|------|
| M0 (현재) | 공시 알림·조회만 제공. 매매 기능 없음 | **현재 단계** |
| M10 | 모의투자(가상 자산, 실주문 없음) 도입 | 미도입 예정 |
| M11 | 반자동매매: 사용자 직접 승인 후 실주문 | 미도입 예정 |
| M12 | 제한적 자동매매: 검증된 전략 한정 | 미도입 예정 |

> **중요:** M11(반자동매매) 도입 전 반드시 M10 MVP 졸업 게이트(30일 이상 모의투자 검증, 신호 적중률 ≥ 55%, AI 비용/모의순익 ≤ 20%)를 통과해야 한다. 이 게이트를 통과하기 전 실주문 기능은 어떠한 형태로도 제공하지 않는다.

### 필수 고지 문구 방향 (예시 문안)

> **[현재 서비스 범위 안내]**
> 현재 공시on은 공시 정보 제공 서비스만 운영하고 있습니다.
> 주식 매수·매도 주문, 자동매매 기능은 현재 제공되지 않습니다.
> 향후 기능 확장 시 별도 공지 및 이용 약관 갱신을 통해 안내드립니다.

### 노출 위치

| 위치 | 노출 방식 | 시점 |
