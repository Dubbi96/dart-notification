# M0 온보딩 화면 정의서 — 분석 유니버스·Persona 선택

> 작성: 화면(UI) 기획 · 작성일: 2026-06-02
> 상위 문서: [실행 로드맵](../../roadmap/01-execution-roadmap.md) · [M0 기술 계약서](./00-contract.md)
> 구현 기준: `mobile/app/onboarding/index.tsx` 확장, Teal 테마(`lightColors`/`darkColors`), RN Paper, Expo Router

---

## 1. 온보딩 플로우 개요

### 1-1. 플로우 위치 (Expo Router 경로)

```
app/
  onboarding/
    index.tsx          ← 현행(step 1·2 통합)  → M0 확장으로 step 1~4 분리
    _layout.tsx        ← SafeAreaView wrapper (신규, 공통 컨테이너)
```

현행 `index.tsx`는 step 1(관심기업)·step 2(푸시알림)를 단일 컴포넌트의 state로 관리한다.
M0에서는 **4단계**로 확장하며, 파일은 단일 `index.tsx`에서 state(`step: 1~4`) 전환 방식을 유지한다.
(Expo Router 페이지 분리는 추후 리팩토링 시 검토)

### 1-2. 단계 구성

| 단계 | 화면 ID | 제목 | 목적 |
|------|---------|------|------|
| 1단계 | `OB-01` | 관심종목 등록 | 분석 유니버스 설정 (관심종목 1개+ 필수 유도) |
| 2단계 | `OB-02` | 투자 유형 선택 | Persona 4종 선택 (1개 선택 필수) |
| 3단계 | `OB-03` | 비투자자문 고지 | 법적 고지 동의 (필수 확인) |
| 4단계 | `OB-04` | 공시 알림 설정 | 푸시 알림 권한 요청 |

### 1-3. 내비게이션 흐름

```
카카오 로그인 완료
      │
      ▼
[OB-01] 관심종목 등록
  ├── 1개+ 선택 후 "계속하기" ──────────────────▶ [OB-02]
  └── "나중에 하기" ──────────────────────────▶ [OB-02]  (watchlist 미등록 허용)
      │
      ▼
[OB-02] 투자 유형(Persona) 선택
  ├── 1개 선택 후 "계속하기" ──────────────────▶ [OB-03]
  └── "나중에 하기" (건너뜀) ─────────────────▶ [OB-03]  (persona 미선택 허용, 홈 이후 설정 유도)
      │
      ▼
[OB-03] 비투자자문 고지
  ├── "확인했습니다" (동의 체크 + 버튼) ───────▶ [OB-04]
  └── 뒤로가기/닫기 없음 (필수 단계, 스킵 불가)
      │
      ▼
[OB-04] 공시 알림 설정
  ├── "알림 받기" ─────────────────────────────▶ 홈 화면 `/(tabs)/home`
  └── "나중에 하기" ───────────────────────────▶ 홈 화면 `/(tabs)/home`
```

> **뒤로가기 정책**: OB-01~04는 스택이 아닌 state 전환이므로 OS 뒤로가기 인터셉트(BackHandler)로 단계 내 이탈 방지.
> OB-03(고지)는 "이전" 버튼 노출 없이 반드시 동의 후 진행.

### OB-01 관심종목 등록

#### 2-1-1. 목적

투자 모니터링 대상이 될 기업(분석 유니버스)을 1개 이상 등록하도록 유도한다.
M0 수집 파이프라인에서 관심종목 기반 필터가 활성화되므로 최소 1종목 등록을 권장하되 강제하지 않는다.

| **검색 결과 없음** | "'{검색어}'에 해당하는 종목이 없습니다." (Caption, 검색 영역 내) |
| **에러** | Snackbar: "종목 목록을 불러오지 못했습니다. 다시 시도해 주세요." + "재시도" |
| **선택 0개** | 계속하기 버튼 비활성화(`disabled`), 카운트 "0개 선택됨" |
| **선택 1개+** | 계속하기 버튼 활성화, 카운트 "N개 선택됨" |
| **watchlist 등록 중** | 계속하기 버튼 `loading=true`, 스피너 표시 |

#### 2-1-5. 내비게이션

- "계속하기": watchlist mutate 완료 후 `setStep(2)`
- "나중에 하기": mutate 없이 `setStep(2)` (watchlist 미등록)
- watchlist 등록 실패: 스낵바 노출 후 step 2 진행 (실패해도 블로킹하지 않음, 기존 정책 유지)

### OB-02 투자 유형(Persona) 선택

#### 2-2-1. 목적

사용자의 투자 철학에 맞는 공시 해석 관점(Persona)을 선택하게 한다.
M3 AI 분석에서 `PersonaInterpretationTask`가 이 선택을 입력으로 사용한다.
선택된 Persona는 백엔드 `InvestorPersona` 시드(4종)와 매핑된다.

#### 2-2-2. Persona 4종 정의

| Persona 코드 | 표시 이름 | 한 줄 설명 | 아이콘 (Feather) |
|-------------|---------|----------|----------------|
| `VALUE` | 가치투자형 | 기업 본질 가치 대비 저평가 탐색 | `trending-down` (역발상) |
| `GROWTH` | 성장투자형 | 매출·이익 고성장 기업 공시 집중 | `trending-up` |
| `MOMENTUM` | 모멘텀형 | 수급·거래량 급변 공시 빠른 반응 | `zap` |
| `EVENT_DRIVEN` | 이벤트드리븐형 | 계약·자사주·배당 이벤트 집중 분석 | `calendar` |

#### 2-2-5. 상태 정의

| 상태 | 화면 표현 |
|------|---------|
| **초기** | 모두 미선택, 계속하기 비활성화 |
| **1개 선택** | 해당 카드 선택 상태, 계속하기 활성화 |
| **저장 중** | 계속하기 버튼 `loading=true` |
| **에러** | Snackbar: "설정 저장에 실패했습니다. 계속 진행합니다." (비블로킹) |

#### 2-2-6. 내비게이션

- "계속하기": persona 선택값 저장 후 `setStep(3)`
- "나중에 하기": 저장 없이 `setStep(3)`

### OB-03 비투자자문 고지

#### 2-3-1. 목적

투자 결정의 법적 책임이 사용자에게 있음을 고지하고 확인을 받는다.
M3 AI 분석 결과, M6 Buy Score 등 모든 투자 정보 기능 진입 전 반드시 1회 노출한다.
**이 단계는 스킵 불가** — 계속하기 전 체크박스 동의 필수.

#### 2-3-2. 고지 문구 (법적 문구)

```
이 서비스는 DART 공시 기반 정보 제공 서비스입니다.

제공되는 모든 정보(공시 요약·투자 신호·종목 분석)는
투자 참고 자료일 뿐이며, 특정 종목의 매수·매도를
권유하지 않습니다.

투자 결정 및 그에 따른 손실·이익의 책임은
전적으로 투자자 본인에게 있습니다.

AI 분석 결과는 과거 데이터 기반 통계이며
미래 수익을 보장하지 않습니다.
```

#### 2-3-3. 구성요소

#### 2-3-4. 컴포넌트 명세

| 컴포넌트 | Props / 상태 | 비고 |
|---------|-------------|------|
| `StepIndicator` | `current=3, total=4` | |
| `DisclaimerCard` | 고정 텍스트 카드 | `surface` 배경, `warning` 색상 아이콘(Feather `alert-triangle`), `bodySmall` 폰트 |
| `Checkbox` + 레이블 | `checked, onPress` | RN Paper `Checkbox.Item` |
| `TextLink` | "자세한 서비스 이용약관 보기" | `Linking.openURL` 또는 `router.push('/legal/terms')` |
| `Button` (확인하고 시작하기) | `disabled={!agreed}` | `agreed=false` 시 비활성화 |

#### 2-3-5. 상태 정의

| 상태 | 화면 표현 |
|------|---------|
| **초기** | 체크박스 미체크, 버튼 비활성화 |
| **체크 완료** | 버튼 활성화 |
| **버튼 탭 (미체크)** | 버튼 disabled 유지, 체크박스 강조(shake 애니메이션 또는 border 빨강) |

#### 2-3-6. 내비게이션

- "확인하고 시작하기" (체크 완료 상태): `agreedDisclaimer=true` 저장(authStore) 후 `setStep(4)`
- 뒤로가기 없음 (필수 단계)

**고지 노출 위치 요약**: OB-03이 온보딩의 유일한 고지 화면. 온보딩 완료 후 홈에서는 별도 노출 없음.
추후 M6(매수 신호) 화면 진입 시 약식 고지 배너를 추가할 수 있으나 M0 범위 아님.

### OB-04 공시 알림 설정

#### 2-4-1. 목적

Expo Push Notification 권한을 요청하고 디바이스 토큰을 등록한다.
기존 step 2와 동일하며, 진행 인디케이터만 `4단계 / 4`로 변경된다.

#### 2-4-2. 구성요소

```
┌─────────────────────────────┐
│  ● ● ● ●   (진행 인디케이터)  │
│  4단계 / 4                  │
│                             │
│  공시 알림을                 │
│  받아보세요                  │
│  (h1)                       │
│                             │
│  관심 종목의 새 공시가 등록되면  │
│  실시간으로 알려드려요          │
│  (body, textSecondary)      │
│                             │
│       [🔔 아이콘]             │  ← Bell 아이콘 (100px 원형, primaryLight)
│                             │
│  ✓  실시간 공시 알림           │
│  ✓  관심 종목 & 공시 유형별 필터│
│  ✓  언제든 설정에서 변경 가능  │
│                             │
│  ─────────────────────────  │
│  [          알림 받기       ] │
│  [        나중에 하기       ] │
└─────────────────────────────┘
```

#### 2-4-3. 상태 정의

| 상태 | 화면 표현 |
|------|---------|
| **초기** | 버튼 활성, 정적 화면 |
| **권한 요청 중** | "알림 받기" 버튼 `loading=true` |
| **권한 거부** | 토큰 등록 없이 홈으로 이동 (notificationSettings.isEnabled=false 저장) |
| **권한 허용 성공** | 토큰 등록 후 홈으로 이동 |
| **토큰 등록 실패** | Snackbar 노출 후 홈으로 이동 (비블로킹) |

#### 2-4-4. 내비게이션

- "알림 받기": 권한 요청 → 토큰 등록 → `completeOnboarding()` → `router.replace('/(tabs)/home')`
- "나중에 하기": `isEnabled=false` 저장 → `completeOnboarding()` → `router.replace('/(tabs)/home')`

## 3. 공통 컴포넌트

### 3-1. StepIndicator

```
● ● ○ ○   (현재 단계 teal dot, 미완 단계 gray dot)
2단계 / 4
```

- 상단 좌측, `alignSelf: 'flex-start'`
- Dot: 크기 8px, 완료·현재 = `primary`, 미완 = `border`
- 텍스트: `captionMedium`, `primary` 색상, `primaryLight` 배경 pill

### 3-2. PersonaCard

```typescript
// 컴포넌트 구조 (참고용)
interface PersonaCardProps {
  code: 'VALUE' | 'GROWTH' | 'MOMENTUM' | 'EVENT_DRIVEN';
  title: string;        // 예: "가치투자형"
  description: string;  // 예: "기업 본질 가치 대비 저평가 탐색"
  icon: string;         // Feather 아이콘 이름
  isSelected: boolean;
  onPress: () => void;
}
```

- 미선택: `surface` bg, `border` 테두리 1px, `radius.md`
- 선택: `primaryLight` bg, `primary` 테두리 2px, 우측 Feather `check-circle` 아이콘(`primary` 색)
- 레이아웃: 아이콘(왼쪽 36px 원) + 텍스트 블록 + 체크(우측)
- 간격: `marginBottom: spacing.sm`

### 3-3. 진행 상태 바 (ProgressBar)

4단계 대신 상단 얇은 선형 진행 바 옵션:
```
[████████░░░░░░░░]  (2/4 = 50%)
```
- RN Paper `ProgressBar`, `progress={step / 4}`, `color={colors.primary}`
- 스텝 도트 방식과 선택적으로 교체 가능
