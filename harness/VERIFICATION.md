# 검증 프로토콜

완료는 주장이 아니라 증거다. Developer는 아래 증거를 PR에 첨부한다.

## 6대 증거
| # | 항목 | 증거 형태 |
|---|------|-----------|
| 1 | 테스트 통과 | 테스트 실행 출력 |
| 2 | 타입체크 통과 | typecheck 명령 출력 |
| 3 | 린트 통과 | lint 명령 출력 |
| 4 | 동작 재현 | 변경 기능을 직접 호출한 결정론적 체크 결과 |
| 5 | 회귀 확인 | 기존 동작 미파손 확인 출력 |
| 6 | 수용 기준 충족 | 기획 작업 시: 수용 기준 항목별 1:1 매핑 |

## 검증 보고 양식
- 요구사항 R1 → 증거: ...
- 요구사항 R2 → 증거: ...
- 미충족 항목: (있으면 사유)

## 규칙
- 증거 없는 요구사항은 미충족으로 간주.
- 6번은 기획 산출물 기반 작업에만 적용.
