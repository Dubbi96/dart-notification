# 도구 레지스트리

PHASE 0에서 실제 package.json 스크립트로 갱신. 아래는 표준 후보.

## 허용 명령
| 명령 | 용도 |
|------|------|
| 빌드 | 프로덕션 빌드 |
| 테스트 | 단위·통합 테스트 |
| 타입체크 | 타입 검증 |
| 린트 | 정적 분석 |

## 승인 필요 (위험)
| 명령 | 사유 |
|------|------|
| prisma migrate | DB 스키마 변경 |
| prisma db reset | 데이터 삭제 |
| git push / PR merge | 원격 반영 |
| rm 대량 삭제 | 파일 손실 |
